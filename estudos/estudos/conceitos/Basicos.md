-> Contexto: Em muitas entrevistas tecnicas e de conhecimento o entrevistador vai perguntar a 
origem do framework e da linguagem.

1 - Como surgiu o .NET? Qual é a sua historia?
R = o .NET foi criado pela microsoft e o primeiro framwork chamava .NET FRAMEWORK, ele ainda
existe e recebe suporte porque muitas empresas ainda usam ela, mas ela parou de "evoluir".
Depois disso foi criado o .NET CORE voltado para ser multiplataforma (antes so rodava no 
windows), ela é mais leve e rapido, tambem foi descontinuado. A partir de 2020 o .NET unificou
tudo, onde la voltou a ser chamada somente de .NET.

2 - O que é ASP.NET CORE?
R = É o framework que roda em cima do .NET. Nele você pode criar APIS REST, sites mvc e 
aplicações web em geral.

3 - O que é um framework?
R = Framework é um facilitador, ele é um conjunto de ferramentas, bibliotecas e convenções qie
te dão uma estrutura pra desenvolver. ele resolve problemas comuns de rota, acesso ao banco
autenticação etc..

4 - Qual é a diferença de um framework para uam biblioteca?
R = Na biblioteca você chama o codigo dela. No framework ele chama o seu codigo, framework 
controla o fluxo e você preenche as lacunas com a ajuda das bibliotecas.

5 - O que é CLI?
R = Ela pode ser tanto a especificação tecnica do .NET quanto a linha de comando dele, dotnet
que você usa no terminal (run,build,new etc)

6 - O que é NuGet?
R = É um gerenciador de pacotes do .NET equivalente ao npm do node.js. É de onde vem as depend
encias do seu projeto.
