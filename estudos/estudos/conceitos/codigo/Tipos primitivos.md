## CONTEXTO: Tipos primitivos, system, byte, numeros inteiros, numeros reais
## boolean,

-> Tipos Primitivos:
	- São conhecidos como built-int types
	- São chamdos tipos de valor
	- Armazenam o valor e n ão a referencia para um item na memoria
	- São classificados em:
		= Tipos simples (Simple types)
		= Enumeradores (enums)
		= Estruturas (structs)
		= Tipos nulos (nullble types)
-> System:
	- No .NET tudo começa de um tipe de base chamado system
	- Não precisamos nos preocupar em usa-lo qualquer cois similar
	- seu uso já é implicito
-> Byte:
	- Utilizado para representar um byte de fato
	- Em diversos casos precisamos da cadeia de bytes de um arquivo, por exemplo
	- tambem chamado de byte array
-> Numeros inteiros:
	- Existem alguns tipos inteiros:
		= Short
		= int
		= long
	- Nos numers por padrao sao pernitidos valores negativos
	- o tipo int é o mais comum de ser encontrado
-> Numeros reais:
	- Existem alguns tipos de numeros reais:
		= float
		= double
		= decimal
	- o double é o mais comum de ser encontrado
-> Boolean:
	- Tipo booliano, apenas true ou false
	- definido pela palavra reservada bool
